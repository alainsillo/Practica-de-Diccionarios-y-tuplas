# Ontología de Identificación de Animales

Practica desarrollada en Python para representar hechos, relaciones y reglas de inferencia a partir de una actividad de adquisición de conocimiento.

### Contenido
- `hechos_ornitorrinco.py`: gestión de hechos mediante diccionarios, tuplas y reglas lógicas.
- `ontologia.md`: representación de la ontología mediante un diagrama Mermaid.
- `reporte_practica_ontologia.docx`: reporte de la práctica.

### Ejecución

```bash
python hechos_ornitorrinco.py
```
